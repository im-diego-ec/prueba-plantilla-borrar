# Runbooks

**Qué hago cuando suena esta alarma**, escrito para las tres de la mañana. Quien
lo lee está apurado, probablemente no escribió el sistema, y no tiene que
deducir nada.

**Un archivo por alarma**, con el nombre de la alarma:

```
docs/runbooks/latencia-alta-en-la-api.md
```

**Qué contesta**:

1. **Qué significa esta alarma** — en una frase, sin jerga.
2. **Qué mirar primero** — el comando o el tablero exacto, para copiar.
3. **Las causas conocidas**, de la más común a la menos, cada una con **cómo se
   confirma** y **cómo se sale**.
4. **Cuándo escalar, y a quién.**
5. **Qué NO hacer** — la sección que más se agradece.

**No se escriben por adelantado.** Un runbook para una alarma que no existe
describe un sistema imaginario, y el día que la alarma exista de verdad nadie va
a confiar en él.
